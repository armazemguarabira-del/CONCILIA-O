# Gestão de Perdas & Conciliação de Estoque

Plataforma profissional de conciliação física e fiscal de estoque, equalização de perdas (quebras, vales, trocas, faltas) e inteligência de chamados de inversão de produtos Ambev.

---

## 🚀 Como Executar o Projeto Localmente

```bash
# 1. Instalar as dependências
npm install

# 2. Iniciar o servidor de desenvolvimento Vite
npm run dev

# 3. Compilar para produção
npm run build
```

O aplicativo estará disponível em `http://localhost:3000`.

---

## 🌐 Publicação no GitHub Pages (Online)

Este repositório já inclui o fluxo automático de deploy em `.github/workflows/deploy.yml`.

Para ativar o link da sua aplicação no ar pelo GitHub:
1. No seu repositório no GitHub, clique na aba **Settings** (Configurações).
2. No menu lateral esquerdo, clique em **Pages**.
3. Em **Build and deployment** > **Source**, selecione **GitHub Actions**.
4. Pronto! O GitHub irá compilar o Vite automaticamente e gerar o seu link de acesso online.
